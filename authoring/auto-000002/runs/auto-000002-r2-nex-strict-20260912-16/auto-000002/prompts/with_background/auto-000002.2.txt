For constant velocity a, use the first-order upwind numerical flux at each interface: if a >= 0, use the left periodic neighbor at the interface; if a < 0, use the right periodic neighbor. Return the semi-discrete derivative - (F_right - F_left) / dx. This operator is the first-order finite-volume building block for advection; it must conserve the cell average on a periodic grid and wrap across both boundaries.
The conservative form is q_t = - (F_right - F_left) / dx. A first-order upwind flux chooses the upstream side of each interface: left of the interface for positive velocity and right of the interface for negative velocity. The sign of the velocity therefore changes which periodic neighbor supplies the interface flux, while the periodic derivative still has zero mean.


def upwind_flux_difference(q: np.ndarray, velocity: float, dx: float) -> np.ndarray:
    """Return the periodic first-order upwind derivative -d(a q)/dx for constant velocity."""
    flux = velocity * q

    if velocity >= 0:
        flux_right = flux
        flux_left = np.roll(flux, 1, axis=0)
    else:
        flux_right = np.roll(flux, -1, axis=0)
        flux_left = flux

    derivative = -(flux_right - flux_left) / dx
    return derivative
